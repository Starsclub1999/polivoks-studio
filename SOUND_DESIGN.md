# Звуковая книга 4.0

Каждый рецепт имеет устойчивый ID, собственную артикуляцию и описание слышимой роли. Общей операции «вторая версия для каждого жанра» в банке нет.

В таблицах указаны рекомендуемые музыкальные роли. Фабричные партитуры связаны с конкретным тембром, а не с приблизительно похожим типом из другого банка.

## Современные

| Тип | Тембр | Характер |
|---|---|---|
| Bass | Резиновая диафрагма | Упругий закрывающийся квадрат с коротким верхним обертоном; для синкопированного баса. |
| Lead | Призма с гранью | Полуторная кольцевая примесь даёт стеклянный край поверх устойчивой мелодии. |
| ARP | Счётчик ртутных капель | Узкий импульс раскрывается резонансным щелчком и сразу освобождает место следующей ноте. |
| Pad | Медленно раскрытый полиэдр | Длинное раскрытие фильтра превращает тёмную октавную пыль в светящиеся струны. |
| Keys | Керамический электрик | Деревянная атака и мягкий третий обертон; сила нажатия заметно меняет яркость. |
| Bell | Кварц с двойным изломом | Высокий семикратный модулятор оставляет негармонический холодный звон. |
| FX | Пакет радиационных искр | Шумовой полосовой разряд прыгает по частотам; высота клавиши меняет центр искр. |
| AMP | Удар по углепластику | Короткая тональная перкуссия с металлическим фронтом и сухим низким телом. |
