# ПОЛИВОКС / SOUNDBOOK 3.0 — GitHub Pages

Готовый статический синтезатор. Загрузите файлы на GitHub Pages: посетители
смогут играть, сочинять музыку, редактировать ноты и записывать WAV в браузере.
Серверная часть, Node.js, npm и аккаунты посетителям не нужны.

## Публикация

1. Распакуйте архив полностью.
2. В новом или существующем репозитории загрузите **содержимое архива**:
   `index.html`, папки `assets`, `js`, `audio`, файл `.nojekyll` и инструкции.
   Сам ZIP загружать вместо файлов сайта не нужно.
3. `index.html` должен быть в **корне репозитория**, без дополнительной вложенной папки.
4. Сделайте **Commit changes**.
5. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
   Выберите **main**, папку **/(root)** и **Save**.
6. Дождитесь публикации и откройте адрес, который покажет GitHub Pages:
   `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
7. Нажмите **ВКЛЮЧИТЬ ЗВУК**. Начальный тест и прогрев выполняются один раз
   при включении аудио; после этого работают экранные клавиши и компьютерная клавиатура.

Для GitHub Free нужен публичный репозиторий. Сборка поддерживает как сайт
в корне `username.github.io`, так и адрес с именем репозитория.
При обновлении заменяйте файлы целиком. Имена файлов чувствительны к регистру.
JS/CSS и аудиомодули имеют номер версии в URL для предотвращения смешивания
кэшированных модулей разных сборок. Service worker не устанавливается.

## Библиотека

- **776 тембров**: 680 новых в 34 жанрах и 96 классических.
- **612 программ композитора**: по 18 на жанр; четыре такта с нотами,
  паузами, артикуляцией, гармонией и переходами.
- **92 набора барабанов**: 68 новых и 24 классических.
- **472 ритмические программы**: 408 новых четырёхтактных и 64 классических.
- Отдельные фильтры жанра/типа/поиска, независимые пресеты и транспорты.
- Piano roll, MIDI import/export, проекты JSON и стереозапись WAV.

Новые тембры используют разные осцилляторные, фильтровые и огибающие рецепты.
Во вкладке **ПАРАМЕТРЫ → СИНТЕЗ+**: отношения частот, фазовая и кольцевая
модуляция, PWM, стереохорус, кассетное плавание и цифровая зернистость.
Именные банки — музыкальные стилизации, не официальные патчи исполнителей.
808/909/Linn — синтезированные стилизации, без сэмплов реальных машин.

**РЕЖИМ ИЗ ПРЕСЕТА** включает нужную архитектуру. Новые тембры требуют
расширенного режима; без него дополнительные параметры не действуют.
**FX ИЗ ПРЕСЕТА** загружает общие эффекты студии, слышимые и на ударных.
Хорус и кассетная окраска из СИНТЕЗ+ обрабатывают только синтезатор.

**ТЕМБР К ФРАЗЕ** подбирает звук при загрузке программы композитора.
Отключите галочку, чтобы оставить свой тембр. Барабанные рисунки при этом
сохраняются. Для новых ритмов **ВСЕ 4 ТАКТА** загружает A–D; без галочки
меняется только выбранный такт. Выбор ритма не переключает набор барабанов.

## Аудио и задержка

Ядро сохранено и расширено: polyBLEP-генераторы, нелинейный фильтр 2×,
сглаживание и очистка DC. Добавлены отдельные модели мембраны, дерева,
металлических мод и шумовой атаки барабанов.

- **АВТО** — стартовый тест 16 голосов и выбор профиля по его результатам.
- **LIVE** — DSP в AudioWorklet, без дополнительной PCM-очереди.
- **PCM 43 мс** — короткий резерв звука в отдельном Worker.
- **PCM 128 / 341 мс** — больший резерв и соответствующая дополнительная задержка.

Режимы сохраняют один алгоритм синтеза. Снижать качество или число голосов
автоматически студия не будет. Нулевая задержка и отсутствие заиканий
на любом ПК не обещаются: остаются браузер, драйвер и устройство вывода.
Стартовый тест — синтетический ориентир, не измерение задержки в наушниках.
Счётчик провалов относится только к PCM-очереди; в LIVE такие провалы
не измеряются. В микшере есть чистый тестовый тон и выгрузка диагностики.

Сторонняя библиотека не добавлена: Faust/WASM могут быть полезны для
конкретного порта DSP, но сами по себе не гарантируют меньшую задержку.
В этой сборке оптимизированы собственный расчёт и запуск. При выключенных
новых расширениях численная разница проверенного синтезаторного сигнала
от предыдущего ядра была менее 8e-9 по пику отсчёта.

## Память и совместимость

Сессия и личные пресеты сохраняются локально в браузере. Для переноса
используйте JSON-проекты. Читаются прежние проекты v1/v2; новые проекты
сохраняют устойчивые ID банков и параметры СИНТЕЗ+. Если прежней фабричной записи
уже нет, её звук и ноты показываются как импортированные из проекта — новый
фабричный пресет не подменяет сохранённые настройки.
Старая версия не сможет полностью воспроизвести новые расширения.

**ПАМЯТЬ / ОЧИСТКА** позволяет скачать и восстановить резервную копию.
Очистка сохраняет личные тембры и шаблоны по умолчанию; их удаление
включается отдельной галочкой. Данные других приложений не очищаются.
Память localhost и GitHub Pages не переносится автоматически.

## Локальная проверка

В распакованной папке, если установлен Python 3:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. На macOS/Linux обычно используется `python3`.
Двойной клик по `index.html` через `file://` не подходит для аудиомодулей.
Для опубликованного сайта Python не требуется — GitHub Pages раздаёт файлы.

## Что проверено

Программный прогон всех 680 новых тембров и всех каналов 68 новых наборов:
конечный непустой сигнал, контроль пиков, сравнение спектров атаки пар.
Проверены загрузка библиотек, параметры, 612 нотных программ, 408 новых
ритмов, независимость разделов, жанровые фильтры и сохранение проекта.
Сжатие данных библиотек обратимо и сверено без потери чисел и событий.
Подробности — `VALIDATION.md`.

В этой сборке не выполнены новая проверка в настоящем браузере и проверка
на физических FiiO / Steinberg. Реальная публикация в вашем репозитории
не выполнялась. Откройте опубликованный сайт и проверьте звук на своём ПК.

Эмуляция характера Поливокса приближённая; это не измеренная точная копия схемы.
Графика корпуса и шкал сохранена. Полное руководство — во вкладке **ПАСПОРТ**.
