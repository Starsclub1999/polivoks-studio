# ПОЛИВОКС / CURATED 4.0 — GitHub Pages

Статическая браузерная музыкальная студия: синтезатор, отдельный композитор
с редактором нот, отдельная драм-машина и осциллограф. Все файлы находятся
в этом архиве; npm, сборка, CDN и серверная часть для сайта не нужны.

## Запуск сайта

Распакуйте архив и загрузите **его содержимое** в корень репозитория:
`index.html`, `.nojekyll`, `assets/`, `js/`, `audio/` должны оставаться рядом.
Включите GitHub Pages для этой ветки и корневой папки. После публикации
откройте HTTPS-адрес сайта и нажмите **ВКЛЮЧИТЬ ЗВУК**.

Пути относительные: студия работает и по адресу репозитория вида
`https://имя.github.io/название-проекта/`. Секреты, токены и API-ключи не нужны.
Публикация в ваш аккаунт автоматически не выполняется.

Для локальной проверки запустите в распакованной папке:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/`. На Windows вместо `python3` может
использоваться `py`. Двойной клик по HTML даёт инструкцию запуска:
браузеры ограничивают AudioWorklet при открытии через `file://`.

## Что изменилось

- **272 заново спроектированных тембра**: по 8 в 34 жанрах. Убраны одинаковые
  «вторые версии» и прежние автоматически полученные альтернативы.
- **544 партитуры композитора**: по 2 на тембр и по 16 на жанр. Огибающие
  определяют подходящую длину нот. Партии дронов, шумов и перкуссии получили
  свои события; клавиши — свои аккорды, одноголосные оригинальные тембры —
  одноголосные рисунки. Все программы редактируются в piano roll.
- **136 ритмов**: по 4 самостоятельные четырёхтактные аранжировки на жанр.
  Меняются сами удары и паузы, а не только темп или velocity.
- **68 новых наборов ударных**: по 2 на жанр. Для каждого отдельно заданы
  семь частот, семь затуханий, тон, атака, модель корпуса, шум и окраска.

Сокращение фабричного списка сделано ради различий между звуками. Структура
типов зависит от жанра; пустые подменю скрыты. Режим и общие эффекты можно
загружать вместе с тембром соответствующими галочками.

Именные банки — музыкальные стилизации. Это не официальные настройки
исполнителей, не сэмплы с записей и не утверждение об использованном ими
оборудовании. Модель Поливокса приближённая: измерения физического экземпляра
и доказательство совпадения с ним в этом релизе не выполнялись.

## Независимые устройства

Фраза композитора меняет ноты и, при включённом «ТЕМБР К ФРАЗЕ», звук
синтезатора. Фабричные партитуры задают последовательность A–B–C–D дважды,
чтобы длинные ноты проходили такты последовательно. Барабанные матрицы
при загрузке фразы сохраняются.

Загрузка набора ударных сохраняет ритм и ноты. Загрузка ритма сохраняет
набор и синтезатор. Темп и swing берутся из ритма только по отдельной
галочке. Темп общий, транспорты включаются независимо.

## Старые проекты и личные записи

Память браузера сохраняет прежний префикс. Личные тембры и шаблоны не удаляются.
JSON-проекты прежних выпусков можно открыть обычной кнопкой. Их реальные
параметры, ноты и ударные восстанавливаются как импортированные записи,
без подстановки новой фабричной записи под старым числовым индексом.

92 старых рецепта наборов хранятся внутри данных исключительно для
восстановления проектов v2/v3 и в фабричном выборе не отображаются.
Новые проекты дополнительно сохраняют полный рецепт текущего набора.
Это данные совместимости, которые не проигрываются сами и не создают
фоновый звуковой тракт. Service Worker в приложении отсутствует.

## Аудио

Основной DSP сохранён. Исправлен порядок применения дискретных параметров:
новые живые ноты сразу получают выбранный унисон и лимит голосов. Для
длинных полифонических тембров доступно до 16 голосов, чтобы отпускание
аккорда не обрывало следующий. Этот лимит не создаёт неиспользуемые голоса.
Банки — данные, они не
вычисляются все одновременно. Действуют существующие профили АВТО,
LIVE и PCM 43 / 128 / 341 мс. PCM-профили добавляют указанную очередь;
большой буфер не ускоряет DSP. В LIVE нет дополнительной PCM-очереди,
но остаётся задержка браузера и устройства вывода.

В расширенном тракте доступны фазовая и кольцевая модуляция, отношения
частот, PWM, хорус, плавание ленты и цифровое зерно. 20 фабричных тембров
используют исходный режим; 252 — расширенный. Выбор профиля не сокращает
полифонию автоматически. При проблеме с выводом используйте «ЧИСТЫЙ ТОН»
и сохранение JSON-диагностики во вкладке микшера.

Подробности рецептов: `SOUND_DESIGN.md`. Проведённые проверки и их
ограничения: `VALIDATION.md`.
