# Проверка LONG TAPE 5.0

## Синтезатор

Исполнены все 1700 рецептов на MIDI 48 и 60 при 48 кГц: 3400 проб.
Длительность пробы для Pad/Drone — 6,8 с (gate 5,6 с), для остальных —
2,4 с (gate 1,65 с). Delay/Reverb отключены; локальные хорус, PWM,
фазовая и кольцевая обработка, зерно и плавание сохранены.

Семь временных окон анализировались FFT 4096 и 48 логарифмическими
полосами. Нормализованная огибающая сравнивалась отдельно от громкости.
Сравнение охватывает 981750 пар внутри групп медленных/быстрых тембров,
включая разные жанры и типы. Отбор близких пар: спектральная дистанция
<0,12 одновременно со средним различием огибающих <0,13.
После перенастройки 318 новых патчей отобранных пар — 0.

Нет одинаковых полных параметров, ID или названий. Все пробы конечны,
активны и не достигли лимита выходного ограничителя; максимальный пик
0.290356. Это численная проверка вероятных дублей, а не доказательство
субъективной различимости каждой пары. Полная слуховая экспертиза всех
1700 тембров и сравнение с физическим Поливоксом не проводились.

## Музыкальные программы

Все 688 нотных форм различаются даже после удаления velocity и темпа
и нормализации высот относительно самой низкой ноты. Все 688 драм-партий
различаются расположением событий при удалении velocity. Все связанные
ID существуют; длины нотных и парных барабанных программ совпадают.
При родном темпе каждая находится в проверенном диапазоне 55–65 с.
Проверены границы нот, их длины, режим связанного звука и независимость
загрузчиков. В каждой из 340 групп жанр/тип ровно пять тембров.

Наборы ударных (68) сохранены из 4.0, их рецепт проверен на точность
переноса. В 4.0 были исполнены все 476 отдельных каналов; в этом выпуске
повторены runtime-проверки ударных, переключений и совместного исполнения.

## Длинные файлы и транспорт

- MIDI на 256 тактов: ноты 0 и 127, дробные начала/длительности,
  каналы, изменения темпа, оригинальные GM-номера ударов.
- Полный MIDI round-trip на 4096 тактов, 140 000 нот и 4096 смен темпа.
  В тестовом окружении загрузка, экспорт и повторный разбор заняли
  1632 мс; это ориентир для тестовой машины.
- Sustain, повторные одинаковые ноты, SMPTE и явное отклонение
  повреждённых данных. Проверена сохранность состояния после
  отклонённого превышения границ.
- Обрезка не удаляет ноты; JSON v5 сохраняет скрытые события,
  дробные удары и диапазон. Старый порядок тактов разворачивается.
- Редактирование MIDI-ячейки сохраняет другие события; навигация
  и копирование проверены после 1024-го такта.
- Полная минутная партитура с удержанными аккордами и ударными
  прошла планировщик без ресинхронизации; однократный транспорт
  остановился в конце, note-off не вышли за выбранную границу.

## Аудиомодули

Проверены готовность LIVE, точная запись 20480 отсчётов, планирование
с точностью до отсчёта, отпускание голосов при смене режима, удар после
panic, передача/возврат PCM-буферов и обнаружение намеренного underrun.
Проверено, что семь расширений меняют сигнал и обходятся в исходном
режиме. Дискретные параметры применяются перед следующей живой нотой.
Контроллер разблокирует звук по нажатию, использует относительные URL
и допускает повтор после ошибки запуска.

## Реальный браузер

Chromium 153.0.8010.0, headless; защита origin не отключалась.

- GitHub-style repository subpath boots with all new banks; DSP loads on demand
- Genre/type submenu selects the actual curated patch
- Composer-linked patch forces Extended with automatic manual-patch mode disabled
- Composer loads genre notes and its recommended sound in the browser
- Drum kit and rhythm loading leave piano-roll notes intact
- Canvas piano roll responds to note entry and undo
- Lower drum tape slider and upper hardware arrow navigate long arrangements
- Dragging the thick ruler crops playback without deleting hidden notes
- 8-voice unison + drums / 128 ms PCM / recording / 85 ms UI stall: no queue underruns
- 16 active pad voices + drums: no PCM queue underruns
- Direct AudioWorklet starts and renders a live note
- Browser project round-trip preserves the selected kit
- Rendered instrument art supplies the preserved preview.png metadata target
- Tablet layout contains the editors and readable controls
- Personal presets survive the bank update
- Actual MIDI file input imports both long tracks and labels imported programs
- Long MIDI export downloads a real SMF from the UI
- file:// gives launch guidance instead of a silent broken instrument
- Non-silent finite WAV; no unhandled page errors

Необработанных JS-ошибок и ошибок загрузки модулей в этом тесте не было.
Записан конечный ненулевой стерео WAV. Проверены макеты 1600 и 768 px.

Использовался виртуальный аудиовывод. FiiO, Steinberg, Bluetooth,
Safari/Firefox и сквозная задержка до наушников не тестировались.
